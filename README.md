**Predicción de defectos en producción**
Proyecto de Machine Learning Supervisado aplicado al caso de estudio de la empresa fabricante XYZ Inc.

**Objetivo**
Predecir si un lote de producción será defectuoso o no defectuoso utilizando variables relacionadas con el proceso productivo.

**Variables**
- Temperatura
- Presión
- Velocidad
- Horas de operación
- Vibración

**Modelos implementados**
- Regresión Logística
- Árbol de decisión
- Bosque aleatorio
- Máquina de vectores de soporte
- K Vecino más cercano
- Bayes ingenuo

**Métricas**
- Los modelos fueron evaluados mediante:
- Exactitud
- Precisión
- Recordar
- Puntuación F1
- Matriz de confusión

**Herramientas**
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
